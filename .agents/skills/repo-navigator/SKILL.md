# Навигация по MythweldWeb

Применять, когда нужно определить, где реализована затронутая Issue функция или маршрут.

1. Прочитать текущую Issue и корневой `AGENTS.md`; проверить `git status --short`
   и текущую ветку. Найти нужный раздел `docs/architecture.md`.
2. Сначала пути: `rg --files src tests scripts`; затем символ или импорт:
   `rg -n 'PUBLIC_PATHS' src/config src/pages tests`. Ограничивать каталог по задаче.
3. Если Serena реально доступна среди инструментов сессии и поддерживает этот проект,
   использовать её поиск/ссылки на символы. Не предполагать доступность и не устанавливать
   её ради навигации. Fallback: `rg`, либо `git grep -n 'PUBLIC_PATHS' -- src tests`.
4. Читать найденную функцию/диапазон и прямых потребителей; расширять поиск только
   при конкретном пробеле. Не загружать все исходники, документацию, ассеты или чужие репозитории.
5. Для release/production читать нужный раздел `docs/current-state.md`, затем только
   релевантный gate/runbook. Датированные наблюдения владельца отделять от кода и новых проверок.

Результат: короткая карта «путь/символ → роль в Issue → нужная проверка» и оставшиеся
вопросы. Поиск не разрешает инфраструктурные изменения или расширение scope.
