## 1. Посетитель сайта

```text
Посетитель → DNS-резолвер → Cloudflare authoritative DNS (DNS only)
Посетитель → VK CDN → при необходимости VK Cloud Object Storage → статический ответ
                         ↳ возможные технические журналы, не публичный контент
```

DNS разрешает имя отдельно; он не получает HTTP URL или письма из-за одной лишь этой роли. DNS-запрос может приходить от резолвера, а не напрямую от посетителя. На CDN/S3 не предполагаются одинаковые поля или хранение каждого поля.

**Баланс интересов для решения OD-07 (предложение):** запрос инициирует посетитель; получение сетевых данных необходимо для доставки. Защита не должна превращаться в отслеживание. Ограничения — минимум данных/доступа, отсутствие маркетинга и сопоставления с письмами, информирование и процедура прав. Возможные последствия — идентификация по совокупности полей и раскрытие истории запросов; необходимость хранения и собственных целей провайдера не выводится из необходимости передачи пакетов. Это аргументы для проверки, а не готовая легализация любой обработки провайдера.

## 2. Отправитель письма

```text
Отправитель / его почтовый сервис → Beget: mythweld@mythweld.com
                                      ↕ чтение и обработка оператором
                                      → исходящий ответ → сервис/адресат отправителя
```

По сообщению владельца письма хранятся только в Beget, переадресации нет. Это не аудит IMAP/POP, устройств, резервных копий или международных маршрутов. Не подразумевается копирование письма в GitHub, облачные AI-сервисы или публичные Issue.

**Баланс для обычного письма (предложение):** инициатор ожидает ответ на свой вопрос; использовать адрес и релевантный текст необходимо для ответа. Не собирать удостоверения личности для обычной поддержки, не обогащать профиль данными сайта, не передавать письмо в стороннюю обработку. Риски — лишние вложения, сведения третьих лиц, утечка ящика. Согласовать альтернативное основание, если эта узкая модель не подходит; поручение проверяется независимо.
