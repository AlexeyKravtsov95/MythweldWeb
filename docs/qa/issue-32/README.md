## Браузерная матрица

Реальный Google Chrome **156.0.8078.80**, headless Chromium на macOS,
viewport высотой 900 px, DPR 1. Playwright 1.58.2 и axe-core 4.11.1 установлены
во временную папку вне проекта; зависимости проекта не менялись.
Это автоматизированный browser QA, а не эмуляция HTML-тестами.

Каждый PASS означает: все изображения декодируются, нет JS/HTTP-ошибок;
`scrollWidth = viewport`, элементы не выходят за горизонтальные границы
(допуск округления 1 px); видимые ссылки/кнопки ≥44×44; измеренный контраст
текста ≥4,5:1; пройдены все доступные элементы через настоящий Tab,
`:focus-visible`/outline ≥2 px без clip-path, элемент прокручивается в viewport;
смена локали через Enter сохраняет страницу. На 320/390/768 дополнительно
проверены Enter → открытие меню, Tab внутрь, Escape → закрытие и возврат фокуса.

- Все 10 страниц: локализованные `lang`, title/description, один h1;
  canonical, парные hreflang EN/RU, x-default на EN, OG/Twitter и существующие
  share cards. Sitemap содержит ровно 10 URL и 30 alternates.
- Все внутренние ссылки, в том числе якоря на **других** страницах, разрешаются
  в `dist/`; Community отмечена в навигации и содержит оба якоря поддержки.
  EN/RU переключается на соответствующую страницу, не на главную.

- `LEGAL` и `legal.pages.*` остаются `null`; публичных store URL нет. B6 —

- Community использует только утверждённый invite, `noopener noreferrer`,

## Проверки и воспроизведение

На Node **24.15.0**, npm ci по исходному lockfile:
`npm run verify` — формат, Astro/TS, сборка, **656 тестов / 15 файлов**;
`npm run secrets:check` — tracked files + dist;
`npm run deploy:plan` — локальный dry-run, без AWS CLI/учётных данных/сети.
Результаты всех трёх команд: **PASS**. GitHub CI проверяется отдельно в PR.

Browser QA запускается дополнительно, не заменяет verify и не добавляет
зависимостей в проект:

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4322
```

В другом терминале на Node 24 (нужен установленный Google Chrome):

```bash
qa_tools_dir="$(mktemp -d)"
npm install --prefix "$qa_tools_dir" --no-package-lock --save-exact playwright@1.58.2 axe-core@4.11.1
QA_TOOLS="$qa_tools_dir" node docs/qa/issue-32/browser-qa.mjs
```

`QA_CHROME` позволяет задать путь Chrome на другой ОС; `QA_BASE` — только
localhost/127.0.0.1 с портом, чтобы случайно не запустить сценарий на production.
Прогон перезаписывает датированные JSON/скриншоты локально. HTTPS read-only
сравнение отдельно: `node docs/qa/issue-32/production-qa.mjs` (требуется `dist/`).

## Оставшиеся риски и передача владельцу

[Пошаговый preflight/postdeploy/rollback](owner-checklist.md) составлен чтением
workflow/scripts/runbook. Возможность записи/удаления и актуальные environment
protections не проверены практическим deploy; это ограничение данного QA.
Публикация неатомарная; откат заново собирает SHA, зависит от доступности
зависимостей/Actions и кэша, старые `_astro/` сохраняются.

Юридическое approval, indexing и production deploy запрещены этим результатом.
B7/данные инфраструктуры, актуальность статусов перед релизом, доступность
CurseForge за challenge, `www`, OG-превью в мессенджерах, Core Web Vitals на
хостинге и команды аддона в игре остаются у владельца. Браузерная матрица
не покрывает Safari/Firefox, реальные устройства, screen reader, увеличенный
шрифт/200% zoom или ручной визуальный просмотр всех 40 сценариев. Lighthouse
из старых документов — история, новый Lighthouse/performance не заявляется.
После PR работа останавливается на ревью; merge/deploy выполняет только владелец.
