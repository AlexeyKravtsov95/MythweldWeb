# Готовность к релизу — состояние на 2026-10-31

Актуализация контекста в [Issue #16](https://github.com/AlexeyKravtsov95/MythweldWeb/issues/16)
после WEB-M0.6A / PR #15. По сведениям владельца от **2026-10-30**, `mythweld.com`
уже доступен через VK CDN: HTTPS `/` и `/ru/` → HTTP/2 200, TLS 1.3,
Let's Encrypt до 2027-01-28; HTTP → 200 без редиректа. Это наблюдения владельца,
не повторная сетевая проверка агента. Подробнее: [current-state.md](current-state.md).

**Техническая доступность не закрывает B6/B7 и не означает release approval.**
В коде по-прежнему `RELEASE.checked = 2026-10-26`, legal-адреса `null`,
`robots.txt` — `Disallow: /`. Индексация закрыта до отдельного решения владельца;
robots не ограничивает доступ по URL. WEB-M0.6B — отдельная инженерная Issue.

Легенда: **GO** — ранее закрыто по материалам WEB-M0.5 (2026-10-27);
браузерный QA и Lighthouse ниже — исторические результаты, не новый прогон.
Состояние конфигов и маршрутов сверено с репозиторием на 2026-10-31.
**NO-GO** — блокирует утверждение публичного релиза. **Владелец** — требуется его решение/действие.

## Оставшийся чек-лист публичного релиза (отдельная Issue WEB-M0.6B)

Ниже будущие действия после согласования, а не выполненные шаги Issue #16.

1. Владелец утверждает Privacy, Terms и Contact (B7) → страницы EN/RU → адреса в `src/config/legal.ts`.
2. Владелец подтверждает статусы магазинов и обновляет `RELEASE.checked` (B6); ссылки — только на опубликованные листинги.
3. Хостинг уже работает через VK Cloud Object Storage + CDN (сведения владельца, Issue #16; runbook — `docs/deploy-vk-cloud.md`). Требуется подтвердить журналы и cookies провайдера (раздел 11 runbook) и отразить их в утверждённом Privacy.
4. Проверка в игре: `/fj open`, Export Book, `/reload` → импорт в Book Creator.
5. Домен: TLS, `www` → apex (или наоборот), `http` → `https`, `/en/` не существует, `trailingSlash: "always"` совпадает с редиректами хостинга, отсутствующий URL отдаёт `404.html` со статусом 404 или — допустимо по решению владельца (Issue #14) — 403 с той же страницей; smoke-тест `npm run smoke` без FAIL. Перед снятием `Disallow: /` владелец ещё раз оценивает SEO-риск 403 вместо 404.
6. `public/robots.txt`: `Disallow: /` → `Allow: /` и строка `Sitemap: https://mythweld.com/sitemap.xml`. Одновременно обновить тест `keeps robots.txt closed until the WEB-M0.6 launch` в `tests/release.test.ts` и тест `does not advertise the sitemap…` в `tests/build.test.ts` — это и есть переключение release gate. Тот же шаг снимает защиту `Disallow: /` в `scripts/deploy/objects.ts` и проверку в `scripts/deploy/smoke.ts`.
7. После деплоя: превью ссылок (OG) в мессенджерах для `/` и `/ru/`, Lighthouse на проде, Search Console (по решению владельца).
8. `journal.mythweld.com`, `legal.mythweld.com`, `ota.mythweld.com` не трогать.
