## Браузер

- EN и RU: ширины 320, 390, 768 и 1440 px; `scrollWidth === innerWidth`, изображения загружены, видимые интерактивные цели не меньше 44×44 px. Мобильное меню дополнительно проверено открытым.
- Клавиатура: Tab/Enter открывают меню; Escape закрывает его с возвратом фокуса. Skip-link переводит фокус в `main`; основной CTA получает видимый outline 2 px без обрезки.
- Переключение RU → EN сохраняет путь `/book-creator/`; canonical соответствует EN. Статические тесты проверяют обе стороны, hreflang и язык.
- Lighthouse snapshot: Accessibility **100**, SEO **100**, Best Practices **100** для EN/RU, desktop и mobile. Это аудит текущего DOM, не замер производительности и не проверка production.
- На странице один основной запуск внешнего инструмента; шапка и прежний пользовательский сценарий сохраняют прямой доступ. Подвал и краткий раздел Forever Journey ведут на обзор.
